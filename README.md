# Java DevOps EKS Project

A complete end-to-end Java DevOps project covering application build,
code quality, artifact management, CI/CD, containerization,
Infrastructure as Code, Kubernetes deployment, Helm, and monitoring.

## Planned Technology Stack

- Java
- Maven
- Apache Tomcat
- SonarQube
- Nexus Repository
- Jenkins
- Docker
- AWS
- Amazon ECR
- Terraform
- Amazon EKS
- Helm
- Prometheus
- Grafana
